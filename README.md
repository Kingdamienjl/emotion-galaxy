# Emotion Galaxy

A living 3D emotion galaxy visualization — 140 emotion states rendered as a breathing cosmic entity.

## Build
```bash
python3 build.py
```
Outputs `galaxy.html` — a self-contained WebGL visualization.

## Elements
Fire, lightning, wind, smoke, sunlight, sparkle, snow, solar flares, supernovae — each mapped to emotional tones and blended by the 6-dimensional emotion coordinates.
